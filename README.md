# Домашнее задание: Вычисление площади и отрисовка геометрической фигуры

## 1. Алгоритм

1. Начало.
2. Ввод данных: `x_mx` (абсцисса) и `y_mx` (ордината) — координаты точки, задающей максимальные размеры фигуры.
3. Вызов функции `square(x_mx, y_mx)`:
   * Вычисление площади описанного прямоугольника: `s_sq = x_mx * y_mx`.
   * Вычисление площади первого отсекаемого треугольника: `s_tr1 = x_mx * y_mx / 2`.
   * Вычисление площади второго отсекаемого треугольника: `s_tr2 = (x_mx - 2) * (y_mx - 4) / 2`.
   * Вычисление итоговой площади фигуры: `s_f = s_sq - s_tr1 - s_tr2`.
4. Вывод значения площади `s_f` на экран.
5. Вызов функции `draw_figure(x_mx, y_mx)` для визуализации фигуры в консоли:
   * Запуск внешнего цикла по `y` от `y_mx` до 0 (строки).
   * Запуск внутреннего цикла по `x` от 0 до `x_mx` (столбцы).
   * Вычисление границ фигуры для текущей точки: `y1`, `y2`, `x1`, `x2`.
   * Проверка условия: если точка находится внутри заданных границ `(x >= x1 && y >= y1) && (x <= x2 && y <= y2)`, выводится символ `*`, иначе — пробел.
   * Переход на новую строку после завершения внутреннего цикла.
6. Конец.

## 2. Реализация программы

```c
#include <stdio.h>
#include <math.h>
#include <locale.h>
#define _CRT_SECURE_NO_WARNINGS

double square(double x_mx, double y_mx);
void draw_figure(double x_mx, double y_mx);

void main() {
    setlocale(LC_ALL, "RUS");
    double x_mx, y_mx;
    
    puts("Введите абсциссу точки: ");
    scanf("%lf", &x_mx);
    
    puts("Введите ординату точки: ");
    scanf("%lf", &y_mx);
    
    printf("Площадь данной фигуры равна: %lf", square(x_mx, y_mx));
    printf("\n");
    draw_figure(x_mx, y_mx);
}

double square(double x_mx, double y_mx) {
    double s_sq, s_tr1, s_tr2, s_f;
    s_sq = x_mx * y_mx;
    s_tr1 = x_mx * y_mx / 2;
    s_tr2 = (x_mx - 2) * (y_mx - 4) / 2;
    s_f = s_sq - s_tr1 - s_tr2;
    return s_f;
}

int draw_figure(double x_mx, double y_mx) {
    double y1, y2, x1, x2;
    for (double y = y_mx; y >= 0; y--) {
        for (double x = 0; x <= x_mx; x++) {
            y1 = -2 * x - 6;
            y2 = -x + 6;
            x1 = (y - 4) / -2;
            x2 = 6 - y;
            if ((x >= x1 && y >= y1) && (x <= x2 && y <= y2))
                printf("*");
            else
                printf(" ");
        }
        printf("\n");
    }
}
```
